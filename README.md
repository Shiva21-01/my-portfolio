# 🚀 Personal Portfolio Website
A modern, responsive, and interactive personal portfolio website built to showcase my web development skills, background, and projects.

* **Personal Portfolio**
  Clean, responsive developer portfolio showcasing frontend and full-stack projects.
  * Live Demo: [shiva21-01.github.io/my-portfolio](https://shiva21-01.github.io/my-portfolio/)


## ✨ Features

* **Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop devices.
* **Interactive UI/UX:** Smooth layouts, dynamic animations, and clean styling.
* **Project Showcase:** Sections dedicated to highlighting full-stack web applications and technical projects.
* **Contact Integration:** Includes a structured contact form framework.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Styling & Effects:** Modern CSS Grid, Flexbox, and custom animations
